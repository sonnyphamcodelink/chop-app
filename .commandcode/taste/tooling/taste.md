# Taste

- Wants third-party skill/plugin bundles (e.g., Superpowers) wired into Command Code at the machine level so they're available by default in every project — not per-project opt-in — and prefers reusing existing installs (Claude Code plugin cache, repo-level config) rather than duplicating content. Confidence: 0.9
- Targets both Windows and macOS; releases should include a Windows installer (e.g., chop-win-x64.exe) alongside the macOS DMGs rather than macOS-only artifacts. Confidence: 0.85
